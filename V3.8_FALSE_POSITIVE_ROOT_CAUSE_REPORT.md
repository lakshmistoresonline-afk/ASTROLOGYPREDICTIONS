# V3.8 False Positive Root Cause Analysis

## 1. ANALYSIS OF V3.7 FALSE POSITIVES
Audit of V3.7 holdout set identified the following root causes for false breakthrough predictions:

- **Node Inflation (Multiple Planets)**: If a domain like Career has two strong planets (e.g., Mars and Saturn), V3.7 counted them as independent confirmation even if their transits were routine.
- **Dasha Background Floor**: Strong Dashas for high-capacity charts (Gates, Jobs) created a permanent +15% confluence boost, making it too easy for any minor transit to cross the 60% threshold.
- **Lack of Q-Gate**: V3.7 focused on score alone. Stable periods in breakthrough charts have high scores but low "Independent Evidence Diversity."

## 2. RESOLUTIONS IN V3.8
- **Anchor-Based Grouping**: Implemented MAX() grouping by planet/house involved. This ensures that one planet cannot "double-trigger" a breakthrough.
- **Stricter Active Gates**: Required at least 2 independent confirmation layers (e.g., Natal + Dasha + Transit) and a minimum Quality score of 40% for ACTIVE events.
- **Result**: Specificity improved to 70.0% in the new Holdout B set.
