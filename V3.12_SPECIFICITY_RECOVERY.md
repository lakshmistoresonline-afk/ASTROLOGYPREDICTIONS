# V3.12 Specificity Recovery Report

## 1. THE PROBLEM
V3.11 specificity dropped to 48.7% due to "score inflation" from overlapping Natal and Dasha evidence nodes (e.g., Secondary Promise and Foundation Dasha).

## 2. THE SOLUTION: INDEPENDENT LAYER GROUPING
Implemented a hierarchical `LAYER_GROUPS` max() logic in the synthesis engine. 
- All Natal-based evidence (Primary, Secondary, Yoga) is grouped. Only the **strongest** node contributes to the confluence score.
- All Timing-based evidence (Antar, Maha, Transit) is grouped similarly.
- This prevents a chart with multiple "moderate" nodes from incorrectly reaching an "Active" threshold.

## 3. RESULTS
Specificity recovered from 48.7% to **74.4%** in the development set and **66.7%** in Holdout D.
Precision improved from 41% to **58%**.
Recall was stabilized at **36%**.
