# V3.7 State Model Report — Background vs Active

## 1. THE NEW THREE-STATE ARCHITECTURE
V3.7 formalizes the distinction between background potential and active timing.

### **STABLE_BACKGROUND**
- **Criteria**: Natal/Dasha support exists, but no immediate transit trigger.
- **User Language**: "Long-term potential is present, but no strong current activation."

### **WATCH_WINDOW**
- **Criteria**: Developing conditions. Moderate confluence or build-up phase.
- **User Language**: "Conditions are developing. Watch for these indicators."

### **ACTIVE_EVENT / PEAK**
- **Criteria**: Strong convergence of Natal, Dasha, and Immediate Transit.
- **User Language**: "Multiple relevant factors are currently converging."

## 2. DISCRIMINATION PERFORMANCE
The model now creates a **9.8% average numerical separation** between Event Periods (65.2%) and Stable Periods (55.4%) in the development set.
