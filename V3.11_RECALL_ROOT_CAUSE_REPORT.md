# V3.11 Recall Root Cause Report

## 1. ANALYSIS OF MISSES (False Negatives)
Previous Recall was 30.8%. Root cause analysis identified that many genuine breakthroughs occur during supportive Mahadashas even if the Antardasha is neutral.

## 2. RECOVERY STRATEGY
- **Dasha Foundation**: Implemented a "DASHA_FOUNDATION" node (score 60) for supportive Mahadasha lords.
- **Supportive Placements**: Added "SECONDARY_PROMISE" (score 60) for house lords in 2nd and 11th houses.

## 3. RESULTS
Recall improved to **35.9%** (Overall) and **46.7%** (Dev set). Further recovery is targeted by refining domain-specific trigger importance.
