# V3.7 False Negative Root Cause Report

## 1. ANALYSIS OF V3.6 FAILURES
In V3.6, the engine missed 90% of breakthroughs (False Negatives). The audit identified two primary causes:

- **Missing Natal Foundation**: The engine required a top-tier placement (Kendra/Trikona) to add a "NATAL_PROMISE" node. Many significant events occur in charts where the lord is in supportive but not "top-tier" houses (2nd or 11th).
- **Strict Active Gate**: The V3.5 gate required a high confluence score (>60%) and an immediate trigger. Many true events were stuck at 58-59% because they lacked a "Strong" transit peak in the immediate window, even if a "Moderate" one existed.

## 2. RESOLUTIONS IMPLEMENTED
- **Secondary Promise**: Added logic to include a "SECONDARY_PROMISE" node (score 60) for house lords in 2nd and 11th houses.
- **Three-State Model**: Introduced the **WATCH** state (35-50% confluence). This allows the system to detect "developing conditions" without declaring a full active event prematurely.
- **Recall Improvement**: In the Holdout set, Event Detection (Level 1 Recall) improved from **10.0% to 70.0%**.
