# V3.7 Recall Optimization Report

## 1. OBJECTIVE
Improve the system's ability to detect true events (Recall) without increasing false alarms during stable periods (Specificity).

## 2. OPTIMIZATION STRATEGY
- **Proximity Weighting**: Refined the temporal decay of transit triggers. Immediate peaks (±7 days) receive full weight, while near-term triggers (±21 days) are scaled down.
- **Evidence Diversity**: Implemented a "Diversity Bonus" (0.05) when Natal, Dasha, and Transit layers all converge.
- **Transit Convergence**: Introduced a "Convergence Bonus" when multiple independent transits support the same domain.
- **Node Inflation Control**: Updated the synthesis engine to prevent double-counting multiple nodes of the same source type.
